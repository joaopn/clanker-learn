# User guide

This guide is for the person learning with clanker-learn: how to install and start it, make a project for a subject, agree a study plan with the tutor, work through lessons in the sandbox, and keep what the tutor knows about you in your own hands. Start with Getting started; the rest can be read in any order.

| Page | What it covers |
|---|---|
| [Getting started](getting-started.md) | What it needs, `./setup`, `docker compose up`, the first start and the first password, updating, stopping and uninstalling, where your data is kept. |
| [Projects and sandboxes](projects.md) | Making a project, its Config box (start, stop, recreate, agents, brief, limits, destroy), what a sandbox brings back by itself, and the `cl` command. |
| [Goals and the study plan](goals-and-plans.md) | The Goals conversation, the plan card, changes to the plan, and the list of lessons. |
| [Lessons](lessons.md) | The conversation, what the tutor shows, exercises and quick questions, the context line, a lesson's files and switching agent. |
| [Shell, Editor and web apps](workspace.md) | The Shell, the Editor, web-app tabs and Ports, tabs side by side, and the sidebar. |
| [The Knowledge page](knowledge.md) | Your briefs and brief sets, goals and archiving them, global and project insights, Lessons done, History and undo. |
| [Agents and software](agents.md) | Claude Code and pi, logging in, the default agent, the Software section and the editor. |
| [Configuration](configuration.md) | The Settings page, the `./setup` command, sysbox or privileged, a trusted certificate, and the settings in `.env`. |
| [Backups and restore](backups.md) | Making, downloading and removing backups, what they hold, and restoring one. |
| [Security](security.md) | What each part holds, what a sandbox can reach, what is not protected, and how to report a problem. |
| [When it refuses to start](troubleshooting.md) | Each refusal at the start, what it means, and what to do. |
| [FAQ](faq.md) | Short answers to common questions. |
